راهنمای اجرای برنامه‌ی «لیست خرید و آشپزخانه» — نسخه‌ی Apache و MySQL (XAMPP)
================================================================================

۱. توی پنل کنترل XAMPP، کنار Apache و کنار MySQL هر دو رو Start بزن.

۲. ساخت دیتابیس:
   - توی مرورگر برو به آدرس: http://localhost/phpmyadmin
   - از منوی بالا روی تب «Import» بزن.
   - دکمه‌ی «Choose File» رو بزن و فایل schema.sql (همین پوشه) رو انتخاب کن.
   - پایین صفحه دکمه‌ی «Go» رو بزن.
   - اگه درست پیش رفته باشه، یک دیتابیس به اسم khaneh_shopping با یک جدول
     خالی به اسم items ساخته می‌شه.

۳. کپی کردن پوشه‌ی برنامه:
   - کل این پوشه (shopping-app-mysql) رو کپی کن داخل مسیر:
     C:\xampp\htdocs\
   - می‌تونی اسمش رو هرچی خواستی بذاری، مثلاً: C:\xampp\htdocs\shopping

۴. اجرا:
   - توی مرورگر برو به آدرس: http://localhost/shopping
     (یا هر اسمی که به پوشه دادی)

همین! برنامه باید کار کنه.

نکته‌ی مهم درباره‌ی تنظیمات اتصال:
اگه روی MySQL خودت رمز عبور گذاشتی یا اسم کاربری‌ت root نیست، باید فایل db.php
رو باز کنی و این خط‌ها رو مطابق تنظیمات خودت اصلاح کنی:

    $dbHost = 'localhost';
    $dbName = 'khaneh_shopping';
    $dbUser = 'root';
    $dbPass = '';

اگه با خطای «could not find driver» یا خطای اتصال روبرو شدی:
مطمئن شو که سرویس MySQL توی XAMPP روشنه (چراغش سبز باشه)، و اسم دیتابیس
دقیقاً khaneh_shopping باشه (همونی که از schema.sql ساخته شد).
